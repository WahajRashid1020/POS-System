# QuickServe POS

AI-enhanced point-of-sale system. Stack: Next.js (App Router), TypeScript,
MongoDB, Tailwind CSS, NextAuth, Socket.io, Stripe, Recharts, OpenAI API.

## Rules
- Stay in scope. Only touch files related to the task — ask before changing anything else.
- Don't modify auth (NextAuth) or Stripe/payment files without confirming with me first.
- Write/update tests for any change. Run the test suite and confirm it passes before saying you're done.
- TypeScript stays strict — no `any`, no skipping types.

## Commands
- Dev: `npm run dev`
- Test: `npm test`
- Lint: `npm run lint`
